# Data Structures and Algorithms

This repository contains my Data Structures and Algorithms (DSA) lab assignments and practice problems, completed as part of my coursework.

## 📂 Folder Structure

| Folder | Description |
|---|---|
| `DSA Lab_Assig_01` | Node and NTS (Node-based structure) implementation |
| `DSA Lab_Assig_02` | Node-based linked list practice |
| `DSA Lab_Assig_03` | Linked list operations (insert/delete), matrix min-max, sum above/below diagonal |
| `DSA Lab_Assig_04` | Sorting algorithms implementation |
| `DSA Problems` | General practice problems (Account, Animal, Employee, Rectangle, MyDate classes) |

## 🛠️ Tech Stack

- **Language:** Java
- **IDE:** NetBeans

## 🎯 Purpose

This repo is a personal record of my DSA lab work — implementing core data structures (linked lists, arrays, matrices) and algorithms (sorting) from scratch, along with test classes for each.
